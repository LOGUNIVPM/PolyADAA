**PolyADAA - a novel method for aliasing reduction in memoryless nonlinearities**

Author: Leonardo Gabrielli <l.gabrielli@staff.univpm.it>

This code accompanies the submission of the paper "PolyADAA: Improving Aliasing Reduction in Memoryless Nonlinearities
Using Lagrange Interpolation and Polynomial Approximation" by L. Gabrielli and S. Squartini, to appear at the 29th Int. Conference on Digital Audio Effects (DAFx26), Cambridge MA, USA.
